Lỗi kết nối thiết bị

Connection closed unexpectedly
🔧 Sửa nhanh bằng công cụ Apple Seed
  1. Bấm tải gói Fix-ADB xuống máy tính.
  2. Giải nén file ZIP → mở thư mục.
  3. Chạy Fix-ADB.bat bằng quyền Administrator nếu Windows yêu cầu.
  4. Chờ chạy xong, rút/cắm lại USB rồi quay lại trang.
  5. Bấm Kết nối thiết bị lại.

Công cụ chỉ xử lý tiến trình ADB/USB trên chính máy Windows của bạn.
